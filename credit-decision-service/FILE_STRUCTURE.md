# Credit Decision Service - File Structure

This repository is a Spring Boot service for handling credit decision requests.

## Root-level structure

```text
credit-decision-service/
├── .github/
│   └── workflows/
│       └── ci.yml
├── .mvn/
│   └── wrapper/
├── .vscode/
├── .gitattributes
├── .gitignore
├── HELP.md
├── Credit-Decision-Tests.postman_collection.json
├── mvnw
├── mvnw.cmd
├── pom.xml
├── src/
│   ├── main/
│   │   ├── java/
│   │   │   └── com/
│   │   │       └── synchrony/
│   │   │           └── credit/
│   │   │               ├── controller/
│   │   │               │   ├── CreditDecisionController.java
│   │   │               │   └── GlobalExceptionHandler.java
│   │   │               ├── dto/

│   │   │               │   └── CreditDecisionResponse.java
```

## Key files

- `pom.xml` — Maven project configuration and dependencies
- `mvnw` / `mvnw.cmd` — Maven wrapper scripts for running builds locally
- `src/main/java/com/synchrony/credit/controller/CreditDecisionController.java` — REST endpoint for credit decisions
- `src/main/java/com/synchrony/credit/service/CreditDecisionService.java` — application logic for decision evaluation
- `src/main/java/com/synchrony/credit/dto/` — request and response models
- `src/main/resources/application.properties` — application configuration
- `src/test/java/com/synchrony/credit/credit_decision_service/CreditDecisionApiTest.java` — API-level test coverage
- `Credit-Decision-Tests.postman_collection.json` — Postman collection for testing API requests
- `.github/workflows/ci.yml` — CI workflow

## Notes

- The `target/` directory is generated by the Maven build and is usually safe to ignore in normal development.
- Hidden folders such as `.github`, `.mvn`, and `.vscode` contain repository automation and editor settings.
